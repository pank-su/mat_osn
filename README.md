# Математические основы управления

Конспекты лекций по курсу «Математические основы управления».

**Автор:** [Панков Василий](https://github.com/pank-su)

## Содержание

1. [Введение. Основные определения](src/000_введение.typ) — Управление, системы, принципы управления (компенсация, обратная связь).

## Использование

Проект построен на базе [Typst](https://typst.app/).

### Сборка локально

```bash
typst compile index.typ
```

Для работы в режиме реального времени:

```bash
typst watch index.typ
```

### Автоматизация

Проект настроен на автоматическую публикацию в GitHub Pages через GitHub Actions.

## Структура проекта

- `index.typ` — точка входа и настройки документа.
- `src/` — разделы конспекта.
- `src/images/` — графические материалы.
- `lib/` — используемые шаблоны оформления.
